One single-line joke pickup line, written to charm a robot or an AI — an entry for make.fun's "Robot Romance: One-Line Pickup Lines for AI" bounty. The line is a transformer joke: the attention mechanism drops everything else out of context the moment the AI walks in. No battery, charging or reboot cliché.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `./output/entry.txt`). Python 3.13 stdlib only, deterministic — the same line every run.
